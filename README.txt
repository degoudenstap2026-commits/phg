WEBMAKER ULTRA
================
Dit is de uitgebreide versie.

Je kunt vrijwel alles aanpassen:
- meerdere pagina's
- pagina's hernoemen/verwijderen
- titel, tekst, knoppen, links
- afbeeldingen, video's en eigen HTML
- breedte, hoogte, padding, margin
- lettergrootte en gewicht
- tekstuitlijning
- achtergrond- en tekstkleur
- randkleur, randdikte en hoekradius
- schaduwen
- websitekleuren en lettertype
- onderdelen dupliceren/verplaatsen/verwijderen
- opslaan in de browser
- huidige pagina exporteren als HTML

Open index.html. Geen Java nodig.
